# Market Indicators Dashboard 요구사항정의서

## 1. 개요

### 1.1 프로젝트 명
- **Market Indicators Dashboard**
- 한글명: 시장지표 대시보드

### 1.2 추진 배경 및 목적
본 프로젝트는 Python 기반의 **FinanceDataReader(FDR)** 라이브러리를 활용하여 각국의 주요 시장지표 데이터를 수집하고,
시장지표 추세를 정규화하여 각 지표간 비교 및 흐름을 직관적으로 파악할 수 있는 그래프를 제공하는 것을 목적으로 한다.

---

## 2. 시스템 구성 개요

### 2.1 전체 아키텍처 개요
- 데이터 수집: FinanceDataReader
- 데이터 처리: Python (Pandas, NumPy)
- 시각화: Plotly
- 서비스 형태: Web Dashboard

### 2.2 개발 환경
- Language: Python 3.x
- 주요 라이브러리:
  - FinanceDataReader
  - pandas
  - numpy
  - plotly

### 3.2 데이터 소스
- FinanceDataReader 제공 데이터

### 3.3 수집 조건
- 기간: From일자 ~ To일자 아규먼트
- 주기: 일 단위 (Daily)

### 3.4 아규먼트
- From일자: 포맷 YYYYMMDD, 생략 가능(기본값 19900101)
- To일자: 포맷 YYYYMMDD, 생략 가능(기본값 현재일자)

### 3.5 데이터 처리
- 결측치 처리
- 날짜 기준 정렬

## 6. GitHub Pages 배포 요구사항

### 6.1 배포 목적
- Python으로 분석·생성된 결과를 **GitHub Pages를 통해 정적 웹 형태로 제공**한다.
- 개인 GitHub 포트폴리오 및 외부 공유를 주요 목적으로 한다.

### 6.2 배포 방식
- GitHub Pages의 정적 호스팅 특성을 고려하여 **서버 사이드 Python 실행은 포함하지 않는다.**
- Python은 데이터 수집·분석 및 HTML 생성 용도로만 사용한다.

### 6.3 기술 구성
- 데이터 수집/분석: Python + FinanceDataReader
- 시각화 결과물: HTML 파일
- 배포 채널: GitHub Pages
- 시각화 라이브러리: Plotly

### 6.4 HTML 생성 요구사항
- 그래프는 **단일 HTML 파일(index.html)** 로 생성한다.
- HTML 파일은 외부 서버 의존 없이 단독 실행 가능해야 한다.

### 6.5 콘텐츠 구성
- 페이지 상단: 프로젝트 명칭
- 선택 영역: 시장지표 목록을 나열하고 선택 가능하도록 한다.
- 메인 영역: 선택된 시장지표 그래프
- 하단 영역: 데이터 출처 및 생성 일자 표기
